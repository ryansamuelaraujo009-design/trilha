Perguntas frequentes

Como a Trilha funciona?

De onde vêm as informações das aulas?

Usamos a API pública da Wikipedia (e seus projetos irmãos em outros idiomas). O conteúdo é organizado em aulas, com os links das fontes sempre disponíveis dentro do curso.

Preciso pagar ou criar conta?

Não. O site é gratuito, funciona direto no navegador e salva seu progresso localmente. Nenhuma chave de API é necessária.

Posso usar no celular?

Sim! O layout foi pensado primeiro para telas pequenas, com navegação inferior, botões grandes e leitura confortável.
